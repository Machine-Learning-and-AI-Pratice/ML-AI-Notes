# ML-AI-Notes

## Project Overview
A personal knowledge base and notes repository covering Machine Learning, Deep Learning, NLP, LLMs, RAG, and Python programming concepts.

## Repository Structure

```
ML-AI-Notes/
├── Deep learning/      # Deep learning concepts, architectures, and experiments
├── LLM/                # Large Language Model notes, usage, and experiments
├── Machine Learning/   # Core ML algorithms, techniques, and theory
├── NLP/                # Natural Language Processing concepts and implementations
├── Python/             # Python programming notes, snippets, and utilities
├── RAG/                # Retrieval-Augmented Generation notes and implementations
└── README.md           # Project overview
```

## Notes & Conventions
- Notes are written in Markdown (`.md`) and Jupyter Notebooks (`.ipynb`)
- Code snippets use Python unless otherwise specified
- Each topic folder may contain sub-folders for deeper categorization

## Key Topics
- **Machine Learning**: Supervised/Unsupervised learning, model evaluation, feature engineering
- **Deep Learning**: Neural networks, CNNs, RNNs, Transformers
- **NLP**: Tokenization, embeddings, text classification, sequence models
- **LLM**: Prompt engineering, fine-tuning, API usage, model comparisons
- **RAG**: Vector databases, retrieval pipelines, chunking strategies
- **Python**: Libraries (NumPy, Pandas, PyTorch, scikit-learn, etc.)
